# Binary Options Indicator for MT4

高確率バイナリーオプション次足予測インジケーター

## 機能

### メインインジケーター (BinaryOptionsIndicator.mq4)

- **シグナル矢印**: 複数インジケーターの収束に基づく買い/売りシグナル
  - 青い上向き矢印 = 買い（CALL）
  - 赤い下向き矢印 = 売り（PUT）

- **勝率統計表示**:
  - 100本足、200本足、300本足、500本足ごとの勝率
  - 全期間の勝率とバー数

- **カウントダウンタイマー**: 次の足までの残り時間表示

- **テクニカル指標**:
  - 複数の移動平均線（EMA 5, 10, 21, 50）
  - ボリンジャーバンド

### サブウィンドウインジケーター (BinaryOptionsOscillator.mq4)

- ストキャスティクス（%K, %D）
- RSI
- シグナル強度ヒストグラム

## インストール方法

1. MT4のデータフォルダを開く（ファイル → データフォルダを開く）
2. `MQL4/Indicators/` フォルダに `.mq4` ファイルをコピー
3. MT4を再起動、またはナビゲーターを更新
4. チャートにインジケーターをドラッグ＆ドロップ

## シグナル判定ロジック

以下の指標の収束でシグナルを生成：

1. **RSI**: 売られすぎ/買われすぎからの反転
2. **ストキャスティクス**: クロスオーバー、売られすぎ/買われすぎ
3. **移動平均線**: 価格と MAの位置関係
4. **ボリンジャーバンド**: バンドからの反発
5. **プライスアクション**: ローソク足パターン

## パラメーター設定

### シグナル設定
| パラメーター | デフォルト | 説明 |
|------------|-----------|------|
| RSI_Period | 14 | RSI期間 |
| RSI_Overbought | 70 | 買われすぎレベル |
| RSI_Oversold | 30 | 売られすぎレベル |
| Stoch_K | 14 | ストキャスティクスK期間 |
| Stoch_D | 3 | ストキャスティクスD期間 |

### 移動平均設定
| パラメーター | デフォルト | 説明 |
|------------|-----------|------|
| MA_Fast_Period | 5 | 短期MA |
| MA_Medium_Period | 10 | 中期MA |
| MA_Slow_Period | 21 | 長期MA |
| MA_VerySlow_Period | 50 | 超長期MA |

### 表示設定
| パラメーター | デフォルト | 説明 |
|------------|-----------|------|
| Show_Arrows | true | シグナル矢印表示 |
| Show_Statistics | true | 勝率統計表示 |
| Show_Timer | true | カウントダウン表示 |
| Show_MAs | true | 移動平均線表示 |
| Show_BB | true | ボリンジャーバンド表示 |

## 推奨タイムフレーム

- M1（1分足）〜 M5（5分足）
