# SoloDesk

個人エンジニアが、顧問契約と短期受託の「予定・単価・次アクション・請求タイミング」をスマホで管理するアプリです。

このリポジトリは Expo（React Native）＋ TypeScript の MVP です。ログイン・決済・クラウド同期は含みません。データは端末内（Web では localStorage）に保存します。

## できること

- **ホーム**: 今月の見込み売上（進行中＋請求待ち）、今週の定例／請求／次アクション
- **案件一覧**: 顧問 / 短期実装 / スポット、ステータス、金額のカード
- **案件詳細**: メモ、次アクション、次回定例日、請求予定日
- **追加・編集・削除**: ローカル永続化
- 初回起動時にサンプル案件を入れます（空に見えません）

## 起動方法

依存関係を入れてから Expo を起動します。

```bash
npm install
npx expo start
```

ターミナルで `w` を押すと Web で開けます。最初から Web で見る場合は次でも同じです。

```bash
npx expo start --web
```

Expo Go を使う場合は、表示された QR コードをスマホで読み取ってください。

## 画面

| 画面 | 内容 |
| --- | --- |
| ホーム | 今月の見込み売上、今週の予定 |
| 案件 | カード一覧、ステータス絞り込み、追加 |
| 案件詳細 | メモ・次アクション・定例日・請求日、編集／削除 |
| 案件フォーム | 新規追加と編集 |

見込み売上は **進行中** と **請求待ち** の金額合計です。顧問は月額、短期実装・スポットは見積（または単価）として扱います。

## 技術

- Expo SDK 57 / React Native / TypeScript
- React Navigation（タブ＋スタック）
- AsyncStorage（ローカル保存）

## MVP の対象外

- ログイン／アカウント
- Stripe などの決済
- クラウド同期
- 本番のプッシュ通知
- 投機・トレード系の機能
